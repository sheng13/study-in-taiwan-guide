# 留學台灣指南

海外學生合作完成的畢業專題網站，整理抵臺前後的入學、校園交通、居留、工作許可與銀行資訊。專案以繁體中文靜態頁面為主，搭配 Google 翻譯元件與本機意見回饋示範；校園內容以明新科技大學為主要情境。

[開始瀏覽](#start) · [主題導覽](#pages) · [檔案與擷取腳本](#sources) · [已知限制](#limits) · [資料時效與歸屬](#attribution)

> 這是專題原始檔與內容快照，不是主管機關網站。居留、工作許可、費用、時程與交通資訊可能變動，請勿直接當成現行申辦依據。

<a id="start"></a>
## 開始瀏覽

網站入口是 [專題_1/main_page1.html](專題_1/main_page1.html)，不是根目錄 `index.html`。下載後可用瀏覽器開啟該檔；若要在同一個本機來源下查看回饋示範，可在儲存庫根目錄使用 Python 3 的靜態檔案伺服器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory 專題_1
```

接著開啟：

```text
http://127.0.0.1:8000/main_page1.html
```

這個命令只提供靜態檔案，不會啟動資料庫、登入系統或內容更新排程。Google 翻譯、外部圖示與各頁外站連結仍需網路；離線時不能保證這些功能可用。

所有既有專題檔案都在 `專題_1/`，根目錄沒有套件清單或應用程式後端。閱讀 HTML 不需要先執行擷取腳本。

兩支 Python 腳本都會對外發送請求，並把結果寫入寫死的 Windows 路徑 `D:/專題_1/`。不要把它們當成跨平台的一鍵啟動指令；重新擷取前需另行檢查依賴、輸出位置、來源網站結構與使用條件。本次文件整理沒有執行腳本或重新擷取資料。

<a id="limits"></a>
## 已知限制

- 首頁居留證按鈕原本指向小寫 `arc1.html`，實際檔案為大寫 [ARC1.html](專題_1/ARC1.html)。在區分大小寫的伺服器上可能無法開啟，請先從本頁的正確檔案連結進入；這次只補文件，未修改 HTML。
- 首頁將 `feedback_list.html` 標為「常見問題」，該檔實際顯示的是本機意見列表，並沒有獨立的 FAQ 資料庫。
- 居留證快照內保留來源網站的 `/media/…` 相對連結，以及尚未填妥的地圖連結；本機沒有對應的來源站資源，不應假設所有內嵌連結均可用。
- 翻譯依賴第三方元件，不能保證外部服務可用或譯文準確；重要申辦文字請回到原始來源核對。
- 文件中的頁面用途依現有原始碼整理，未宣稱完成瀏覽器互動測試、外站可用性檢查或正式部署。
